# 🏎 Formula One Live Tracker and Analytics System

A complete Data Science and Sports Analytics mini project built using Python, Streamlit, and Formula One datasets.

This project analyzes Formula One race data and provides visual analytics for:
- Driver standings
- Constructor standings
- Circuit analysis
- Performance trends
- Championship statistics

---

# 📌 Project Overview

The Formula One Live Tracker is a dashboard-based analytics system that helps users explore Formula One racing statistics using interactive visualizations and data analysis techniques.

The project uses:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

The dashboard displays:
- Top drivers
- Team standings
- Circuit country analysis
- Driver performance trends
- Statistical insights

# ⚙ Installation

## Step 1 — Clone Repository

```bash
git clone https://github.com/adishbalachandran/Formula_One_Live_Tracker.git
```

---

## Step 2 — Open Project Folder

```bash
cd formula-one-live-tracker
```

---

## Step 3 — Install Dependencies

```bash
pip install -r requirements.txt
```

---

# ▶ Running the Project

Run the Streamlit application:

```bash
streamlit run app.py
```

After running, open the local server link shown in terminal.

Example:

```text
http://localhost:8501
```
